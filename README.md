Sum up 24 November 2026's world news in one image — a one-page broadsheet, "The World in One Day": a serif masthead naming the day, three illustrated lead stories, a solid-fill world map with big numbered pins for the top 15 stories and a dot for every other story's place, a UTC timeline strip, 12 numbered top-story cards, and a 33-item numbered index in reading order — 48 stories in all. Every story was date-audited to Tuesday 24 November 2026: events recycled by Tuesday digests from earlier days were left out on purpose, and a DATE CHECK box on the poster's face names the excluded stories. Agenda items are labelled TONIGHT / TODAY, never shown as results. The program draws the whole page itself with the Python standard library only (no network): every word is set in type by the program from a bitmap font defined in the code itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
